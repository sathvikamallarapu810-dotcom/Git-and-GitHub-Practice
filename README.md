# 📚 Git Concepts Covered

## 1. Git Repository Initialization

Created a new Git repository using:

```bash
git init
```
---

## 2. Tracking Changes

Checked file status:

```bash
git status
```
Added files to staging area:

```bash
git add .
```

---

## 3. Creating Commits

Saved project changes using:

```bash
git commit -m "commit message"
```

Viewed commit history:

```bash
git log
```

---

## 4. Branch Management

Created a feature branch:

```bash
git branch feature-readme
```

Switched between branches:

```bash
git checkout feature-readme
```

---

## 5. Git Merge

Combined feature branch changes into the main branch:

```bash
git merge feature-readme
```

---

## 6. Remote Repository Connection

Connected local repository with GitHub:

```bash
git remote add origin <repository-url>
```

Verified remote connection:

```bash
git remote -v
```

---

## 7. Push Project to GitHub

Uploaded project changes:

```bash
git push -u origin master
```

---

# 🔄 Git Workflow

```
Working Directory
        |
        ↓
    git add
        |
        ↓
 Staging Area
        |
        ↓
   git commit
        |
        ↓
Local Repository
        |
        ↓
    git push
        |
        ↓
GitHub Repository
```

---

# 🌱 Branching Workflow

```
Main Branch
      |
      |
Feature Branch
      |
      |
Development Changes
      |
      |
Merge Back to Main
```
